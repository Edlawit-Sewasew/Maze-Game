# Maze-Game

Simple maze generator and solver visualization using Pygame.

Contents:
- `solver.py` — solver visualization logic.
- `config.py` — display and color configuration.

Quick start:
1. Install dependencies: `pip install -r requirements.txt`.
2. Run the project with Python: `python solver.py` (project entry may vary).

Add your own maze generator or adjust settings in `config.py`.
